# Security Policy

## Supported Releases

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within Crimson Orbit (such as buffer safety anomalies in raw 16-bit real mode memory segmentation, WebAssembly memory bounds violations, or WebAudio ring buffer race conditions), please do **not** open a public issue.

Instead, please send an advisory email directly to:
**`akash20065ray@gmail.com`**

Include:
1. Description of the vulnerability and security implications.
2. Steps or assembly code to reproduce the issue.
3. Relevant emulator / hypervisor environment (emu8086, QEMU, Chrome version).

We commit to acknowledging your disclosure within 48 hours and working promptly on a resolution and patch release.
